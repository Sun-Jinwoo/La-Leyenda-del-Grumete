# La Leyenda del Grumete — sitio de bitácora

Sitio estático (HTML/CSS/JS). Abre `index.html` para verlo.

## Actualizar cada semana
1. Copia la PLANTILLA comentada en `bitacora.html` y pégala arriba de la entrada anterior.
2. Guarda la evidencia (captura/GIF/video) en `img/` y enlázala.
3. Agrega la versión al "Índice de iteraciones".
4. Los textos con fondo amarillo (`.todo`) son para completar: quita la clase al terminar.

## Publicar gratis
GitHub: sube la carpeta a un repo → Settings → Pages → rama `main`, carpeta `/ (root)`.

## Animaciones
- `js/anime.min.js` es Anime.js 3.2.2 (incluido, no requiere internet). Toda la lógica está en `app.js`.
- Respeta `prefers-reduced-motion` (si el usuario lo activa, se desactivan).
